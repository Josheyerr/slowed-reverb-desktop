# Security

## Supported versions

Security fixes go to the latest release on [Releases](https://github.com/Josheyerr/slowed-reverb-desktop/releases). Older installers aren’t patched separately — update to the newest build.

## Reporting a vulnerability

Please **don’t** open a public issue for security problems.

Use GitHub’s private reporting:

1. Go to the repo → **Security** → **Report a vulnerability**  
   or: https://github.com/Josheyerr/slowed-reverb-desktop/security/advisories/new
2. Include what you found, how to reproduce it, and impact if you know it

I’ll try to reply within a week. If it’s confirmed, a fix will ship in a normal release when ready.

## Scope

In scope: the desktop app, installer, auto-update flow, and this repo’s release process.

Out of scope: third-party tools we call (FFmpeg, yt-dlp, ssstik.io) — report those upstream.
