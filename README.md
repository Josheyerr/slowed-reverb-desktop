## Download

Grab **`Slowed + Reverb-*-Setup.exe`** from the [latest release](https://github.com/Josheyerr/slowed-reverb-desktop/releases/latest).

Install needs admin (Program Files). If Windows complains that it isn’t signed, hit **More info** → **Run anyway**.

See what’s new in the [changelog](CHANGELOG.md).

---

## Features

| | |
|:--|:--|
| **Import anything** | Pretty much any audio file — no extra codecs to install |
| **YouTube & TikTok** | Paste a link and pull the audio straight in |
| **Presets** | Slowed + reverb, nightcore-style, or your own saves |
| **Effects** | Reverb, bass, EQ, pitch / tempo, live A/B bypass |
| **Export** | WAV or MP3 — one track or a whole folder |
| **Updates** | Checks in the background; restart when a new build is ready |

---

## Quick start

1. Install and open the app  
2. Add a file, or paste a YouTube / TikTok URL  
3. Pick a preset or tweak the knobs  
4. Export when you’re happy with it
